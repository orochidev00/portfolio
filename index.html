Combat System V2

2026 · Personal build · Gameplay

ProblemMost Roblox melee is animation clips stacked on each other. Hits have no weight, and the arena doesn't care that a fight is happening.

What I built

  • Five-hit M1 chain, a unique animation per hit, blended so the combo reads as one motion
  • Directional knockback from attacker position — ApplyImpulse on the server for NPCs, LinearVelocity on the client for players
  • Knocked-back targets raycast the wall they hit: bounce with reduced velocity, or break it into physics debris
  • Jump attack with an airborne hitbox and a ground slam shockwave
  • Hit pause on heavies, impact flash and camera shake scaled to hit weight
  • Animations reworked in Blender for anticipation and follow-through

Result

Knockback with no rubber-banding — every body is moved by the machine that owns it. A 6-frame startup keeps the chain responsive.

What I built

  • Eight states — idle, patrol, stalk, toying, chase, look-around, jumpscare, return — one handler each in a dispatch table
  • Two-zone vision: a 95-stud central cone plus a 40-stud peripheral zone, raycast to torso and head
  • Hearing grows from 80 to 140 studs when the player sprints, so sneaking actually matters
  • Stalk picks spots behind the player. Stare at it for 2 seconds and it charges
  • Toying circles out of view and sidesteps if its route would cross the player's sightline
  • 4 Hz proximity feed to each client for heartbeat audio and vignette

Result

Behaviour that reads as intent. It remembers where you were for 4 seconds — long enough to hunt, short enough to escape.

What I built

  • Server-authoritative combo chain: jab, straight, hooks, finisher
  • Hitboxes through GetPartBoundsInBox — one spatial query per swing
  • Parry, guard and stun states
  • Ragdoll: the server swaps joints, the client sets HumanoidState
  • Enemy brain as a dispatch table on CollectionService tags, AlignOrientation for turning, GoodSignal for events

Result

Ragdolls replicate without jitter. Server owns rig state, clients own their movement — new enemy types plug in without touching the core.

Egg Tycoon

2025 · Full game · Economy

ProblemA Steal-a-Brainrot-style game from an empty baseplate, with eggs as the collectible.

What I built

  • Shop with weighted rarity tiers; higher tiers unlock with progression
  • Per-player plots with placement slots
  • Income on one batched server tick, so cost stays flat as the server fills
  • Offline earnings on rejoin, capped so AFK can't break the economy

Economy, persistence and PvP theft built by one scripter, with no data loss on rejoin or server hop.
